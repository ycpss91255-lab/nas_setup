# security:NAS 安全設定

NAS 端的安全相關設定，全部在 NAS 網頁或 myQNAPcloud 網站上手動操作。換 NAS 或重設時照著做。

| 項目 | 擋什麼 | 本機帳號 | LDAP 帳號 |
|---|---|---|---|
| [myQNAPcloud Link 自訂模式](#1-外部連線myqnapcloud-link) | 沒被邀請的人從外部連到 NAS | ✓ | ✓ |
| [IP 存取保護](#2-ip-存取保護) | 同一個 IP 一直猜密碼 | ✓ | ✓ |
| [帳號存取保護](#3-帳號存取保護) | 一直猜某個帳號的密碼 | ✓ | **✗(實測無效)** |
| [管理員兩步驟驗證](#4-管理員帳號) | 管理員密碼外流 | ✓ | — |
| [密碼原則](#5-密碼原則) | 太弱的密碼 | ✓ | 不設 |
| [病毒防護、安全中心](#6-病毒防護安全中心) | 惡意檔案、設定風險 | — | — |

## 1. 外部連線(myQNAPcloud Link)

NAS 在 NAT 後面、路由器沒開埠，從外部連線靠 Link(QNAP 的中繼服務)。

1. App Center 安裝 **myQNAPcloud Link**,用 QNAP ID 登入。
2. **myQNAPcloud 網站**(myqnapcloud.com)→ 設備管理 → 這台 NAS → **權限控管** → 改成 **自訂**。
   - 只有你和你邀請的人能透過 SmartURL 連進來，其他人連 NAS 登入頁都看不到。
   - 要讓別人用：同一頁「+ 新增」,輸入對方的 email 或手機號碼。對方登入自己的 QNAP ID 後，再用自己的 NAS 帳號(本機或 LDAP)登入。
3. **公開服務**(NAS 的 myQNAPcloud App → 存取控制):只發佈要用的服務。
   - 保留:Web Administration、Web File Manager(含 Secure 版本)。
   - 服務本身沒開時(例如 Web Server、QuMagie),發佈開關是鎖住的，無法改，外部也連不到東西。
   - 之後啟用某個服務(例如 Web Server)時，回這頁決定要不要對外發佈。

測試：手機**關掉 Wi-Fi、用行動網路**打開 SmartURL。在內網測試可能直接走內網，測不出來。
- 登入 QNAP ID 後看到 NAS 登入頁 = 正常。
- 無痕視窗、不登入 QNAP ID = 應該被擋。

## 2. IP 存取保護

控制台 → 系統 → 安全設定 → **IP 存取保護**(預設已開):1 分鐘內登入失敗 5 次 → 封鎖該 IP 5 分鐘。

- 失敗次數是**所有帳號合併計算**。同一台電腦連續測試不同帳號，也會被封。
- 封鎖期間那台電腦連 NAS 網頁、SSH 都會斷，時間到自動解除。

## 3. 帳號存取保護

控制台 → 系統 → 安全設定 → **帳號存取保護**:

| 欄位 | 值 | 原因 |
|---|---|---|
| 使用者 | 不屬於管理員群組的所有使用者 | 管理員被鎖就沒人能解鎖 |
| 服務 | 只勾 **HTTP(S)** | NAS 網頁、File Station、Link 都走這個 |
| SMB | 不勾 | Windows 記住舊密碼會一直重試，容易誤鎖 |
| 條件 | 10 分鐘內失敗 10 次 | |

- 觸發後帳號會被**停用**,要管理員到「控制台 → 使用者」手動啟用。
- **對 LDAP 帳號無效**(實測：錯 11 次仍可登入)。LDAP 帳號只受 IP 存取保護。

## 4. 管理員帳號

- 內建 `admin` 停用，改用自己建立的管理員帳號。
- 管理員開啟**兩步驟驗證**(右上角帳號 → 登入與安全性)。

## 5. 密碼原則

控制台 → 系統 → 安全設定 → **密碼原則**:英文字母 + 數字、不可與使用者名稱相同、最小長度 10,不要求定期變更。

- 只管 NAS 本機帳號(設定或變更密碼時檢查)。LDAP 帳號不受影響，也不另外設。

## 6. 病毒防護、安全中心

- **病毒防護**:App Center 安裝 ClamAV → 控制台 → 病毒防護 → 啟用。
  - 病毒定義每天自動更新。
  - 掃描工作：只掃 `share`,每週一次，發現病毒 → **隔離**。
- **安全中心**:App Center 安裝 → 每週自動安全檢查。問「是否把結果傳給 QNAP」選否。
- **韌體更新**:控制台 → 韌體更新 →「只通知我，而不要自動更新」。有更新時先看變更記錄，再挑沒人用的時間更新(會重新開機)。

## 單一帳號的功能限制(選用)

控制台 → 使用者 → 帳號的「**編輯應用程式權限**」,可個別關掉 SMB、AFP、FTP、WebDAV、File Station、Qsync。

- 本機帳號、LDAP 帳號(使用者頁右上角切到「網域使用者」)都有。
- 只能逐一帳號設，群組沒有這個選項。
- 分不出從外部或內網連線，關掉後內網也不能用。
